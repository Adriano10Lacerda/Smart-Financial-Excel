# Smart Financial Excel

## Intelligent Financial Control

Projeto de automação financeira desenvolvido em Microsoft Excel e VBA.

O objetivo é transformar o controle financeiro tradicional em uma ferramenta visual, interativa e fácil de utilizar.

## Funcionalidades planejadas

- Controle de receitas
- Controle de despesas
- Categorias financeiras
- Controle de saldo
- Metas de economia
- Dashboard financeiro
- Indicadores de saúde financeira
- Relatórios
- Interface visual
- Personagem interativo
- Estados visuais conforme a situação financeira
- Automação com VBA

## Tecnologias

- Microsoft Excel
- VBA
- Git
- GitHub
